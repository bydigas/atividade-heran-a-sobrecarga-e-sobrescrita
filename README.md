# Lista de herança, sobrecarga e sobrescrita

Laboratório de Técnicas de Programação Orientada a Objetos.

Cada pasta `ExNN...` é um exercício. Dentro dela estão as classes em Java e a classe `Teste...` com o `main`.

Para rodar um exercício, compile e execute a classe `Teste...` da pasta:

    javac *.java
    java TesteNomeDoExercicio
